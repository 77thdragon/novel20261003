# つみき工房（仮称）

小説を書くためのデスクトップアプリです。断片 → 問い → プロット → 原稿 の流れと、Git による原稿管理を一か所で扱います。

## 起動

デスクトップの **「つみき工房」** をダブルクリックします。
（実体は `dist\TsumikiKobo-win32-x64\TsumikiKobo.exe`。ターミナルは不要です）

ソースを直したあとは、次で exe を作り直します（デスクトップのショートカットも置き直します）。

```
npm install       （初回だけ）
npm run package
```

開発中に exe を作らずに動かすときは `npm start` です。

最初の画面で「作品フォルダを開く」を押し、作品のフォルダ（例：`小説/作品A`）を選びます。
初めて開くフォルダでは、管理用のフォルダ `.tsumiki/` を作ってよいかを確認します。既存のファイルは書き換えません。

## 外部への通信について

- 画面からの通信（http / https / WebSocket）はすべて遮断しています。フォント・CDN・解析・自動更新もありません
- 外に出るのは、履歴画面で「確認」「プル」「プッシュ」を押したときの git 通信だけです。押すと、送信先と送るコミットを確認するダイアログが出ます
- AI は呼びません。つみきくずしは今までどおり Claude Code で実行し、このアプリはその出力ファイルを読むだけです
- 人物・舞台の画像は、初期設定では `.gitignore` に入れて Git に含めません（設定画面のチェックで切り替え）
- 画面下の「ローカル専用」は、この状態であることを示しています

## 画面

| 画面 | できること |
| --- | --- |
| 断片 | その場で書き留める（種類つき）、絞り込み・検索、場面に置く。`断片/YYYY-MM.md` に保存 |
| 問い | つみきくずしの Round ごとの進み具合、成果物・未決事項・蒸留判断の表示、次に実行するコマンドのコピー、SKILL.md の質問への回答メモ |
| プロット | 区間×場面カードのボード（ドラッグで移動・並べ替え）、未配置トレイ、場面の編集、糸（伏線・モチーフ）、区間の編集 |
| 原稿 | ファイル一覧、横書きエディタ（自動保存・文字数・今日の増分）、選んだ文章を断片にする、紐づいた場面と断片の表示 |
| 設定 | 人物（画像つき）、舞台（画像つき）、関係（感情マトリクス）、決定ログ（確定・保留・棄却） |
| 履歴 | Git の開始、変更一覧（文字数の増減つき）、文単位の差分（赤入れ表示）、コミット、履歴、別案（ブランチ）、リモートの設定・確認・プル・プッシュ |

## 作品フォルダに作られるもの

```
原稿/                 原稿ファイル
断片/2026-10.md       断片（月ごと）
資料/人物/, 資料/舞台/  画像（初期設定では Git 管理外）
つみき/               つみきくずしの出力を置く場所（場所は問い画面で変更可）
.tsumiki/             プロット・人物・舞台・決定ログ（JSON。Git で管理）
```

最近開いた作品・テーマ・つみきくずしスキルの場所は、作品フォルダではなく、この PC のアプリ用フォルダに保存します。
